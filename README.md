# Smart Gloves for Sign Language Translation

**An Embedded Systems and Assistive Technology Project**

## 1. Project Overview
This project focuses on developing a smart glove capable of translating hand gestures into audio output to facilitate communication for people with hearing and speech impairments.

The system uses an ESP32 microcontroller, flex sensors, an MPU6050 motion sensor, and a DFPlayer Mini audio module.

## 2. Hardware Components
- ESP32 Microcontroller
- Flex Sensors
- MPU6050 Accelerometer and Gyroscope
- DFPlayer Mini Audio Module
- Electronic connections and power supply

## 3. Technologies and Skills
- Embedded Systems
- Microcontroller Programming
- Sensor Integration
- Arduino IDE
- Electronics Prototyping
- Hardware and Software Integration

## 4. System Architecture
The flex sensors measure finger bending, while the MPU6050 captures hand movement and orientation. The ESP32 processes the sensor readings and controls the audio output module.

## 5. Project Objectives
- Develop a wearable assistive technology prototype.
- Detect and interpret hand gestures.
- Convert recognized gestures into audio output.
- Explore practical applications of embedded systems.
